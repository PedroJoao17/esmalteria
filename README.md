# Esmalteria

MVP frontend mobile-first para uma esmalteria que oferece serviços de manicure, pedicure, alongamentos e também comercializa perfumes, sabonetes e hidratantes.

## Escopo do MVP

- Landing page com proposta de valor e destaques
- Catálogo de serviços e produtos com dados simulados
- Área demonstrativa da cliente
- Painel demonstrativo da administradora
- Identidade visual baseada na paleta de tons de rosa fornecida pela cliente
- Navegação otimizada para celulares
- Base preparada para integração futura com API Java Spring

## Tecnologias

- Next.js 16, React 19 e TypeScript
- CSS responsivo com tokens de design próprios
- Netlify com `@netlify/plugin-nextjs`

## Executar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Validar

```bash
npm run lint
npm run build
```

## Publicação no Netlify

O repositório já inclui `netlify.toml`. No Netlify, importe este repositório, mantenha o diretório base na raiz e publique. O plugin oficial para Next.js cuida da integração.

## Organização do trabalho

O planejamento funcional é mantido no Trello em sprints semanais. O GitHub registra código, documentação e evolução técnica.
